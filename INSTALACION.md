# Instalación paso a paso — SuiteLand

## La primera vez (una sola)

### CurseForge

1. **Minecraft** → **Crear perfil personalizado**
2. **Importar** → selecciona el `.mrpack` de Releases
3. Jugar

### Prism Launcher

1. **Añadir instancia** → **Importar** → **Modrinth** → el `.mrpack`
2. Jugar

### Launcher oficial

1. Instala NeoForge para Minecraft 1.21.1
2. Pon `automodpack.jar` (de Releases) en `.minecraft/mods/`
3. Perfil NeoForge → Jugar

## Después

Nada. Al conectar al server se descargan los cambios solos y reinicia.
Sin cambios → entras directo.

## Problemas

| Síntoma | Solución |
|---|---|
| El pack no descarga | Espera a que AutoModpack termine y reinicia |
| Pantalla roja al conectar | El server está actualizando — reintenta en 2 min |
| Crash al arrancar | Borra `.minecraft/mods/` menos `automodpack.jar` y reintenta |
