# SuiteLand

Servidor Minecraft ATM10 — pack que **se actualiza solo**. Descarga la
instancia, conéctala y juega. Sin tocar nada nunca más.

## 🎮 Cómo entrar

### Opción 1 — Tienes launcher (CurseForge, Prism, Modrinth App)

1. Descarga [`SuiteLand-v1.0.0.mrpack`](../../releases/latest) de las releases
2. En tu launcher: **Importar instancia → Modrinth pack** → elige el `.mrpack`
3. Arranca la instancia → conecta a `37.230.138.123:25575`
4. En la primera conexión se descarga todo el pack (~2 GB, una vez)
5. Listo — cada cambio de pack se aplica solo al conectar

### Opción 2 — Sin nada (launcher oficial de Minecraft)

1. Instala [NeoForge 21.1.267](https://neoforged.net/) para Minecraft 1.21.1
2. Descarga `automodpack.jar` de las releases → mételo en `.minecraft/mods/`
3. Arranca → conecta al server → el resto se descarga solo
