# SuiteLand

Servidor Minecraft con modpack propio que **se actualiza solo**. Instala la
instancia una vez y cada cambio llega automático al conectar.

## 🎮 Cómo entrar

1. Descarga el `.mrpack` de [Releases](../../releases/latest)
2. Impórtalo en tu launcher (CurseForge, Prism, Modrinth App — cualquiera que soporte packs de Modrinth)
3. Arranca y conecta — el resto se descarga solo

Guía completa por launcher: [`INSTALACION.md`](INSTALACION.md)

## 📦 Qué contiene

- Base: All The Mods 10 (Minecraft 1.21.1, NeoForge)
- AutoModpack — sync automático de mods y configs al conectar

## 🔗 Acceso

La IP y el acceso se gestionan por Discord — pide invitación a un admin.
